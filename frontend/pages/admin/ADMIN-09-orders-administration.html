Rider assignment rules

Riders can be assigned after an order is Accepted while the restaurant continues preparation.

Only approved riders with Online and Available status can be selected.

An order can have only one active rider, and a rider can have only one active delivery.

Assignment, reassignment and unassignment are available only before pickup.

After pickup Rider assignment cannot be changed once the order is Picked Up.
