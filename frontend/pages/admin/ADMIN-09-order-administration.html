Administrative cancellation

Administrators can cancel an order while it is Accepted, Preparing or Ready for Pickup, before the rider picks it up.

A cancellation reason is required and must be recorded with the order.

Inventory is restored only when cancellation happens before preparation starts.

Orders already Picked Up must use the failed-delivery flow.

Refund handling Prepaid cancellations are referred for refund resolution. COD orders do not require a refund.
